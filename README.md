# For Veronica

A dreamy, pastel, just-because surprise made for Veronica by Mahal.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Personalize the memories

The page is ready to run with friendly placeholders. Replace these whenever you have Veronica's personal content:

- Edit the letter, reasons, timeline, captions, and gift copy in `src/content.ts`.
- Replace the gallery and reaction images in `public/photos/`.
- Add Mahal's voice note as `public/veronica-voice-note.m4a`.

All core sections are enabled: the running No button, celebration, letter, reasons, timeline, memories, gifts, voice note, and personalized link sharing.
